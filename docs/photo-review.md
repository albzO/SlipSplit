# 照片矫正与确认流程

分支：`codex/dewarpnet-trial`。

拍照和相册统一经过以下流程：

1. 系统相机／系统照片选择器返回单张图片，App 单次读取原始字节保存缓存副本，
   解码最长边 1200 的编辑预览；不再先把整张照片重压为 PNG 后才显示。
2. 原生 OpenCV 在缩小图上自动估计纸张四角，进入“调整小票四角”页面后可微调、重新自动找边或重置整图。
   没有找到可信候选时选择整张照片。自动选框仍需用户确认，避免错误边框直接裁掉内容。
3. 点击“查看矫正效果”：先做四点透视变换并显示结果，绘制完成后再开始曲面矫正。
4. 在“确认矫正效果”页面双指放大检查；切换 DewarpNet / UVDoc 或关闭曲面矫正时自动更新。
5. 确认“使用这张并识别”后，通过单次内存交接把同一张矫正图片交给主界面做 OCR。
   正常流程不保存 `approved.png`，不重新解码或重复运行曲面模型。

预览页可以返回调整四角，或直接重新选图／重新拍照。处理过程中禁止确认旧结果，
快速切换选项时只有最新结果可用；处理失败后仍能调整、切换模型或重新选图。
返回调整时保留四角，“重置四角”才恢复整张图。预览页返回键回到四角调整。
确认之前不会运行 OCR，也不会把未确认照片写入识别记录。

拖动四角时显示带十字准星的偏置放大镜，靠近边缘时换位避开手指；按下时保留抓取位置，
角点不会跳到指尖。已移除重复的副标题、完成耗时和待机说明，仅处理期间或出错时显示状态。

图片在后台解码、应用 EXIF 方向、透视矫正和曲面矫正。编辑四角使用 1200 预览，
点击查看矫正效果时才读取最长边 2400 的处理图，并按比例映射四角；最终矫正预览与 OCR 使用同一个 Bitmap。
原始字节保存为 `source.image`，不受扩展名影响，仍按图片格式解码并应用 EXIF。
缓存位于 `cache/photos/review-<uuid>/`，
系统可在空间不足时回收。已有识别记录仍保存原图、处理图和曲面模型名称／耗时。
识别结果先发布到界面，再由后台线程保存这些记录；可选诊断保存失败不会把成功识别改成失败。
内存交接最多保留一个待消费图片，超时两分钟丢弃引用，防止图片长期驻留。
如果系统恰好在两个页面切换时杀掉进程，内存图片会丢失；此时才使用原图、四角和曲面选项重建，
不会让每次正常确认都等待磁盘保存。缓存原图也已失效时需要重新选图。
DewarpNet 和 UVDoc 在处理结束时释放，不与 OCR 模型同时驻留。
安卓端已移除嵌入式 Python、相关科学计算库及 page-dewarp，构建不再需要 Python 3.10。

## 自动找边

使用原生 OpenCV `4.12.0`，不需要 Google Play services 或网络。检测在工作线程执行，最长边缩至 960 像素。
结合两组 Canny 边缘、闭运算、明暗阈值与 HSV 浅色区域提取轮廓；同时近似原始轮廓和凸包，
适配边缘不完全平直的折皱纸张。按面积、角度及四边的实际边缘支撑度评分。
允许部分边缘超出照片、部分角点贴边，但仍要求至少两条有实际图像支撑的边，避免简单接受整幅图框。
最后将四角映射回编辑预览坐标。原生面积测量只算一次，避免排序时重复调用。

初次导入自动执行；页面恢复时优先保留用户已经调整的四角，不重新覆盖。
“自动找边”允许重新估计，“重置四角”恢复整图。找边使用独立工作线程，期间可以直接拖动、重置或进入预览。
一旦用户触碰角点或重置，当前后台结果就不会覆盖用户操作；进入下一步后也会忽略旧结果。
OpenCV 在主界面后台预热，旧 OCR 会话释放不再挡住校正页打开。
检测失败或本地库无法加载时回退整图，仍能手动调整。算法未针对当前样本调参，白纸白底、遮挡或强阴影可能无法正确选框。
`PhotoReview` 日志记录原图导入、预览解码和找边各自的耗时；OpenCV 异常不再被静默吞掉。

相册选择仍使用系统安全授权，只读取用户选择的图片。已移除 Google 文档扫描器依赖，
梯形矫正和曲面预览由 App 提供，不依赖相册编辑器或 Google Play services。

复跑（先把测试照片放到 App 外部文件目录 `files/smoke.jpg`）：

```powershell
cd android-bridge
./gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest :app:lintDebug
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5554 shell am instrument -w local.ocrbridge.test/local.ocrbridge.PhotoReviewSmoke
```

当前默认测试 runner 是 `PhotoReviewSmoke`。单独运行三模型基准时，在构建设备测试 APK 时传入
`-PsmokeRunner=local.ocrbridge.DewarpSmoke`，再按 `dewarpnet-trial.md` 中的命令运行。
自定义测试成功返回 `INSTRUMENTATION_CODE: -1`，失败时输出 `error`。
