# 原生 OpenCV 自动找边

已从安卓 App 移除 page-dewarp、Chaquopy、Python 源码及相关打包配置。
Windows 上独立安装的 Python，以及本项目电脑端 OCR 工具的 Python 环境不属于安卓嵌入运行时，未卸载。

安卓依赖改为官方 `org.opencv:opencv:4.12.0`。选图后只从系统提供方读一次原始字节，
显示最长边 1200 的小预览；不再等待全图 PNG 重编码或找边完成。
四角编辑与后台找边可以同时进行，用户碰过角点后自动结果不会覆盖手动调整。
可点击“自动找边”重新估计，或“重置四角”恢复整张照片。

自动检测结合较弱的边缘、明暗轮廓、浅色区域、凸包及四边形几何评分，放宽对部分贴边和不规则纸边的限制。
针对两张用户截图中桌面被选中的情况，已进一步调整：

- 移除“面积占主要权重”的评分。对候选四边形内部采样，至少 65% 需要符合浅色纸张条件。
- 检查四条边内外的饱和度与亮度变化，至少两条边有纸张／背景差异，防止木纹和桌面亮斑胜出。
- 浅色区域改用三档更严格的饱和度门槛（30、50、70），替代原先会覆盖大量木桌的 105。
- 候选选定后向外留少量余量，降低折皱边缘和贴边文字被截掉的概率。

缺少清晰候选时保留整图，避免直接提交错误裁剪。
仍保留偏置放大镜，以及先显示梯形校正图、再处理 DewarpNet / UVDoc 的预览流程。
处理阶段仍使用最长边 2400 的原图，通过比例换算保留四角精度，不使用编辑小图做最终 OCR。

## 截图诊断重放

`tools/debug_document_edges.py` 在电脑端使用两张用户截图近似恢复照片区域：
裁掉界面，按已知遮罩透明度补偿亮度，并对四角圆点和青色线做局部修补。
这些是派生诊断图，受 JPEG 压缩、遮罩和修补影响，不能替代原图或 Android 真机验证。

两例重放中，候选均落在小票区域；第二例不再选择桌面下半部。输出在本机 `logs/edge-replay/`，
其中 `comparison.png` 为加余量后的框，`report.json` 记录候选坐标与评分（评分不是概率）。
重放使用电脑 OpenCV 4.10.0，安卓依赖为 4.12.0，仍存在平台与输入差异。

本轮没有重新构建 APK 或操作设备。原图上的准确率及手机耗时尚未验证。
